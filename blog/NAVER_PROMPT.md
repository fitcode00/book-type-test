# Claude in Chrome용 네이버 블로그 입력 프롬프트
로컬에서 레포를 `git pull` 한 뒤, 아래를 Claude in Chrome(또는 로컬 Claude Code + Chrome 연동)에 그대로 붙여넣는다.
`<...>` 부분만 바꾼다.

---

네이버 블로그 글 입력을 도와줘. 규칙을 지켜.

## 대상
- 블로그 id: `<book | food | challenge | travel | date>`
- 네이버 블로그 글쓰기 주소: `<https://blog.naver.com/내아이디/postwrite>`
- 입력할 파일: 레포의 `blog/out/naver/<블로그id>/` 에서 아직 올리지 않은 글 **1개만**

## 절차
1. 내 크롬 탭을 먼저 확인하고, 새 탭에서 위 글쓰기 주소를 연다.
2. 로그인이 안 돼 있으면 멈추고 나에게 알려. 로그인, 캡차, 2단계 인증은 내가 직접 한다.
3. 입력 파일을 읽는다. 첫 줄 `<h1>`은 제목, 나머지는 본문이다.
4. 에디터에 제목을 입력한다.
5. 본문은 HTML을 그대로 타이핑하지 말고, 서식(소제목, 목록, 굵게)이 에디터에서 유지되도록 입력해.
6. `(…)`로 남은 빈칸이나 `<p></p>`처럼 비어 있는 섹션이 있으면 입력하지 말고 목록으로 알려줘.
7. 사진 자리가 있으면 비워두고 "여기에 사진" 위치만 알려줘. 이미지는 내가 넣는다.
8. 카테고리와 태그는 내가 정한다. 건드리지 마.
9. **발행 버튼은 절대 누르지 마.** 입력이 끝나면 미리보기 상태에서 멈추고 결과를 보고해.

## 금지
- 발행, 예약발행, 공개 설정 변경
- 한 번에 2개 이상 글 입력
- 내용 수정이나 추가 (오탈자 발견 시 알려주기만)
- 다른 사이트 방문, 결제나 설정 변경, 알림 팝업 수락

## 보고
입력한 글 제목, 남은 빈칸 목록, 에디터에서 깨진 서식을 짧게 알려줘.

---

## 운영 규칙 (사람이)
- 하루 발행은 블로그당 최대 2~3편.
- 발행은 직접 버튼으로. 여러 블로그를 같은 시간대에 연속 발행하지 않는다.
- 발행한 글은 `blog/out/naver/` 에서 따로 `done/`으로 옮겨 구분한다.
